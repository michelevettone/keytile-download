# KeyTile Download

Downloads for the **KeyTile** companion app: turn your iPhone into a wireless shortcut keypad
for your Mac.

This repository hosts the packaged builds and update metadata — not the source code, which is
private.

## macOS receiver

- **[Releases](../../releases)** — `KeyTileReceiver.zip`, the menu-bar receiver for macOS.
  Grant it Accessibility and Bluetooth, then pair a phone from its menu.
- `minimum.json` — the oldest receiver version KeyTile accepts (compatibility policy).

## iPhone app

The KeyTile iPhone app is distributed separately; the receiver's *Get the iPhone app…* points
here until the App Store listing exists.
